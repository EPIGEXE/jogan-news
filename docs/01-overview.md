# 1. 프로젝트 개요

## 무엇을 하는 프로그램인가

**Jogan(조간)** 은 LLM·AI 에이전트 분야의 소식을 매일 자동으로 모아 한국어로 요약해 주는 Windows 상주형 데스크톱 앱입니다.

출근해서 PC를 켜면 트레이에 상주하던 앱이 그날의 브리핑을 만들고, 완료되면 알림을 띄웁니다. 알림을 누르면 신문 지면처럼 정리된 "오늘" 화면이 열립니다. 여기서 끝나지 않고, 쓸만한 기사를 저장하고 메모해서 **개인 AI 지식 저장소**로 쌓아 가는 것이 목표입니다.

```mermaid
flowchart LR
  A[수집·브리핑<br/>매일 자동] --> B[읽기<br/>오늘 화면]
  B --> C[저장·메모<br/>라이브러리]
  C --> D[다시 찾기<br/>검색·태그·아카이브]
  B --> E[AI에게 질문<br/>기사·브리핑 근거, 문단 인용]
  E --> C
```

## 주요 기능

| 기능 | 설명 |
|---|---|
| 매일 브리핑 | 뉴스·공식 블로그·개발자 블로그·라이브러리 릴리스·논문·커뮤니티에서 수집 → 중복 합치기 → AI 선별 → 같은 소식 묶기 → 한국어 요약 → 영어 기사 본문 전체 번역. 하루 약 20건, 1회 약 $0.02 |
| 자동 실행 | 로그인·잠금 해제(5시 이후) 또는 켜둔 채 오전 8시에 하루 한 번. 네트워크가 늦게 붙으면 최대 5분 기다림. 켜져 있는 동안 2시간마다 수집만 미리 해 둠(LLM 비용 없음) |
| 7일 중복 방지 | 지난 7일 브리핑에 실린 소식은 다시 싣지 않음. 중요한 새 전개가 있으면 "후속" 표시를 달아 실음 |
| 오늘 화면 | 오늘의 한 줄, 섹션별 목록, 기사 패널(요약·왜 중요한가), 기사 읽기 화면(요약·핵심 포인트 3~5개·본문을 한국어 / 원문 / 함께 보기로) |
| 저장·메모 | 저장하면 원문 본문을 문단 단위로 보관하고 AI가 태그를 추천. 줄 노트 메모는 자동 저장 |
| 하이라이트 | 본문 문장을 드래그해 형광펜(H). 번역문·원문 어느 쪽에도 긋고, 하이라이트마다 메모·"이 부분 질문". 그은 기사는 자동 저장 |
| 라이브러리 | 저장한 기사를 제목·요약·본문·메모로 검색, 메모 있는 기사·태그로 필터 |
| 아카이브 | 날짜별 지난 브리핑을 그날 지면 그대로 보기, 지금까지 실린 모든 기사 검색 |
| AI 질문 | 기사 본문을 근거로 묻고 답함. 답변의 ¶번호를 누르면 본문의 그 문단으로 이동. 오늘 브리핑 전체에도 질문(#번호를 누르면 그 기사로). 빠른 질문 버튼, 답변을 메모로 옮기기 |
| 비용 관리 | 월 예산(기본 $5)·하루 상한($0.5)·실행당 토큰 상한. 예산 도달 시 작은 모델로 바꾸는 절약 모드 |

## 기술 스택

| 영역 | 선택 |
|---|---|
| 앱 | Electron (Main · Worker · Renderer 3개 프로세스), TypeScript |
| 화면 | React + Vite + Tailwind CSS v4 (디자인 토큰은 `tokens.css`의 `@theme`) |
| DB | Node 내장 `node:sqlite` (FTS5 전문 검색 포함, 네이티브 모듈 빌드 불필요) |
| LLM | Groq — `openai/gpt-oss-20b`(선별·태그), `openai/gpt-oss-120b`(묶기·요약·머리글) |
| 수집·추출 | `rss-parser`, `@mozilla/readability` + `linkedom` |
| 테스트 | Vitest |

## 디자인: "조간 작업대"

신문 지면의 느낌(명조 제목, 괘선, 종이색, 이탤릭 원제, 강조색 하나)에 작업 도구의 3단 구성(메뉴 / 목록 / 기사 패널)을 합친 디자인입니다. 키보드만으로 훑고(J/K), 저장하고(S), 메모하고(M), 질문하고(/), 원문을 열(Enter) 수 있습니다. 색·크기는 모두 `src/renderer/src/styles/tokens.css`의 토큰으로만 씁니다.

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 0. 사전 검증 | Electron 데스크톱 기능·네트워크 확인, 요약 모델 비교 | 완료 |
| 1. MVP | 수집 → 선별 → 요약 → 오늘 화면 | 완료 |
| 2. 자동 실행 | 트리거·알림·자동 시작, Windows 설치 파일 (낮 동안 미리 수집은 남음) | 대부분 완료 |
| 3. 저장·메모 | 본문 보관, 태그, 라이브러리, 아카이브, 검색 | 완료 |
| 4. AI 질문 | 기사·오늘 브리핑을 근거로 질문, 문단 인용, 빠른 질문, 메모로 옮기기 | 완료 |
| 5. 품질 | 본문 전체 번역, 개발자 소스 확장, 분류 개편(도구·실전), 분류별 최소 몫 | 완료 |
| 6. 마무리 | 하이라이트, 낮 동안 미리 수집, 7일 중복 방지 (내보내기·라이브러리 RAG·개인화는 하지 않기로 함) | 완료 |
